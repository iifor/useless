# UNO Yan Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an independently installable `UNO Yan` desktop pet by reusing the tested UNO PangYu reduced application and replacing only application identity plus character assets.

**Architecture:** Create `pet/uno-yan` in an isolated worktree from PangYu commit `e1f9895`, which contains the reduced action set and later interaction/movement fixes without committed release binaries. Keep the existing runtime and safety code; generate a new hatch-pet v2 atlas, twelve required extension strips, and app icons from the uploaded reference.

**Tech Stack:** Tauri 2, React 19, TypeScript 5.9, Rust 2021, Vitest, hatch-pet v2, imagegen.

**Spec:** `docs/superpowers/specs/2026-08-18-uno-yan-design.md`

## Global Constraints

- The uploaded reference at `/var/folders/8n/_t7zmf6116vcy2yfy6lcr7k00000gn/T/codex-clipboard-590977ea-51c8-4785-89f5-b41a0a785203.png` is the only identity source.
- Preserve pixel-art style, black bob hair, both hair clips, yellow cardigan, white camisole, beige shorts, white socks, and cream high-top shoes.
- Canonical and animations must have transparent backgrounds with no text, props, UI, scenery, or shadows.
- Runtime visible long edge remains exactly `119px`.
- Do not add prone, lie, or sleep actions or assets.
- Do not add a character factory, configuration layer, or reusable scaffold.
- Keep updater and release workflow disabled.
- Do not modify the existing UNO or UNO PangYu worktrees.
- All user-file mutations remain routed through existing `FoodSafety`; do not alter that subsystem.
