# 宠物缩放与独立座位动作设计

## 目标

- 现有运行时人物尺寸再缩小 30%：普通动作从 170px 调整为 119px，趴姿从 145px 调整为 102px。
- 动作菜单新增“坐到当前窗口”和“寻找桌面图标”，便于分别触发和验证两类真实座位。

## 行为

- 自动“寻找桌面座位”保持原规则：当前聚焦窗口 → 现有桌面图标 → 都没有才延迟创建应用自有空文件。
- “坐到当前窗口”只查找当前聚焦且符合安全过滤条件的窗口；没有目标时恢复站立。
- “寻找桌面图标”只查找现有桌面文件或文件夹；没有目标时恢复站立，不创建文件。
- 三个入口复用现有寻找动画、低斜率行走、窗口刷新、落座和安全回收流程。

## 最小实现

- 在现有 `PetAction` 和动作菜单中加入两个手工动作。
- 给现有 `find_seat_targets` 命令增加搜索模式参数，在同一目标提供器内选择 `auto`、`focused-window` 或 `desktop-icon`，避免复制平台代码。
- `seatSequence` 接受搜索模式；自动调度继续使用 `auto`，两个手工动作传入各自模式。
- 无目标的手工模式返回 `null` 并恢复站立；只有 `auto` 模式允许返回延迟自建座位。

## 验证

- TypeScript 测试覆盖菜单项目、动作映射、三种选择模式和无目标行为。
- Rust 测试覆盖模式解析与目标发现分支。
- 运行 `pnpm test`、`pnpm build`、`cargo test`、`cargo check` 和 debug Tauri build。
