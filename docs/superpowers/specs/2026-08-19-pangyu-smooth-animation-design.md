# PangYu 流畅动画设计

## 目标

在不影响 UNO 和 UNO Yan 的前提下，提高 UNO PangYu 的关键动作流畅度：四向慢走由 4 个独立帧升级为 8 帧，吃文件由 4 个独立帧升级为 6 帧。素材必须保持 PangYu 身份、服饰、基线和透明边缘稳定，不能通过重复帧或运行时补间伪造流畅度。

## 范围

本次仅升级以下 PangYu 动作：

- `walk-slow-left`: 8 帧
- `walk-slow-right`: 8 帧
- `walk-slow-up`: 8 帧
- `walk-slow-down`: 8 帧
- `eat-normal`: 6 帧

待机、寻找、落座、查看文件和等待确认继续使用现有 4 帧素材。UNO 与 UNO Yan 的全部扩展动画继续使用现有帧数和素材。

## 角色级动画配置

`character.json` 增加可选的最小覆盖字段，只记录偏离引擎默认值的动作：

```json
{
  "animationOverrides": {
    "walk-slow-left": { "frameCount": 8, "fps": 8 },
    "walk-slow-right": { "frameCount": 8, "fps": 8 },
    "walk-slow-up": { "frameCount": 8, "fps": 8 },
    "walk-slow-down": { "frameCount": 8, "fps": 8 },
    "eat-normal": { "frameCount": 6, "fps": 6 }
  }
}
```

规则：

- 未配置的扩展动画沿用引擎当前默认值。
- 覆盖项只允许引擎已知的扩展动画名称。
- `frameCount` 和 `fps` 必须是正整数，并设置合理上限，防止异常清单导致高频重绘或超大素材。
- 引擎继续拥有动作语义、循环方式和文件路径；角色包只覆盖帧数与播放速度，不获得自定义状态机能力。

## 运行时

构建时注入的角色清单继续作为唯一角色配置来源。`ANIMATIONS` 保留默认协议，解析当前动作时将对应 `animationOverrides` 合并到默认动画定义中。

渲染器继续按实际 `frameCount` 等分横向 strip，并复用现有的：

- alpha 边界分析
- 同动画统一缩放
- 人物横向锚点
- 联合紧凑视口
- 动态原生窗口布局

无需修改移动速度、动作调度、FoodSafety 或文件交互状态顺序。

## 素材生成

以 `characters/uno-pangyu/canonical-base.png` 为唯一身份参考，通过 hatch-pet 与 imagegen 生成五张完整横向 strip。每张 strip 使用纯净键色背景，随后通过 hatch-pet 官方确定性脚本完成透明化、帧提取和检查。

四向走路的 8 帧必须构成完整连续步态：接触、下沉、经过、抬起及对侧对应阶段，首尾可无跳变循环。上下方向必须通过身体与衣摆的前后关系表达方向，不能只是左右素材改名。

吃文件的 6 帧依次表达：观察、靠近/拿起、张嘴、入口、两次咀嚼变化、吞咽满足。文件图标仍由 UI 动态绘制，不能画进角色素材。

所有帧必须保持：

- 同一张 PangYu 面孔、发髻、花簪和垂饰
- 浅桃粉汉服、绿色花纹胸带和紫红飘带
- 相同人物比例、可见长边和光照风格
- 无文字、道具、阴影、场景、动作线或跨槽内容

## 校验与失败处理

角色包校验器根据最终解析出的 `frameCount` 检查每张 PNG：

- PNG 为 RGBA。
- 宽度可被该动作的帧数整除。
- 每帧非空且不跨槽、无裁切。
- 未知覆盖名、非法帧数或非法 FPS 直接拒绝构建。
- 禁用能力仍不要求对应素材，也不读取其覆盖项。

视觉 QA 必须检查五张循环预览，重点关注身份漂移、尺寸跳变、基线跳变、左右闪烁、重复帧、步态倒序和首尾断点。失败时只重做失败的完整 strip，不拼接不同生成批次的单帧。

## 测试与验收

- 清单解析测试：PangYu 正确覆盖 8/6 帧，UNO 与 Yan 仍使用默认 4 帧。
- 校验器测试：按配置检查 strip 可整除性，拒绝未知动作、零值、负值、非整数和过大值。
- 运行时测试：四向走路映射到 8 帧 8 FPS，吃文件映射到 6 帧 6 FPS，其他动作保持原定义。
- 资产测试：五张 PangYu strip 的实际尺寸、RGBA、帧数和非空帧符合清单。
- hatch-pet QA：透明边、角色身份、帧顺序、锚点、基线和循环预览通过。
- 完整运行 `pnpm test`、三个角色的前端构建、Rust test/check，并打包 PangYu debug 应用。
- macOS 实机分别观察四向长距离行走和吃文件流程，确认动画更连续且没有新增左右闪烁。

## 非目标

- 本次不升级 UNO 或 UNO Yan 素材。
- 不为所有动作统一增加帧数。
- 不增加运行时图像插值、补帧、骨骼动画或视频素材。
- 不改变标准 v2 atlas、pet contract、动作概率或移动速度。
- 不开放任意角色脚本或自定义状态机。
