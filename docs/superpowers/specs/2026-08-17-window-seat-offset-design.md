# 窗口座位上移设计

## 目标

- 宠物坐在可视窗口顶部时整体上移 `8 CSS px`。
- 桌面文件、文件夹、自建文件和虚拟座位的位置保持不变。

## 实现

- `seatWindowDestination()` 增加可选的 CSS 垂直偏移参数，默认值为 `0`。
- 该函数使用当前显示器 `scaleFactor` 将 `8 CSS px` 转为物理像素。
- `App.tsx` 仅在目标 `kind === "window"` 时传入 `-8`；首次到达、窗口刷新重定位均使用相同偏移。
- 最终位置继续经过现有 work area 夹取，靠近屏幕顶部时不越界。

## 验证

- 1x 显示器窗口座位上移 8 物理像素。
- 2x 显示器窗口座位上移 16 物理像素。
- 非窗口座位不产生偏移。
- 窗口刷新后的重定位保持相同偏移。
