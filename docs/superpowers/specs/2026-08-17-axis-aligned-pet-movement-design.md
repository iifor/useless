# 宠物轴对齐移动设计

## 目标

宠物从当前位置走向任意目标时，不再沿斜线移动。允许通过一条水平线和一条垂直线组成直角折线路径到达目标；每一段移动必须保持 X 或 Y 坐标不变。

## 现状

`randomWalkTarget` 可以产生任意方向的目标点，`planWalkPath` 当前只返回最终目标，因此 `moveWindowTo` 会通过 `stepTowards` 沿当前位置与目标点之间的斜线移动。随机散步、寻找座位、走向文件等场景共用这条路径规划链路。

## 方案

在 `planWalkPath` 中统一生成轴对齐路径：

1. 先将最终目标限制在显示器工作区内。
2. 如果当前位置与目标位置相同，不生成路径。
3. 如果两点已在同一水平线或同一垂直线上，只返回最终目标。
4. 如果两点同时存在水平和垂直差异，先返回 `{ x: 目标.x, y: 当前.y }` 作为拐点，再返回最终目标。

`moveWindowTo` 和 `stepTowards` 保持不变。由于它们逐段处理路径点，每一帧移动自然只改变一个坐标轴。随机目标仍可分布在整个工作区，不会因为禁止斜线而退化成只能在单一方向活动。

## 边界与兼容性

- 最终目标继续由现有的工作区限制逻辑处理。
- 零长度路径和重复路径点必须删除，避免宠物停顿或方向抖动。
- 方向判断继续使用现有的上、下、左、右动画。
- 所有调用 `planWalkPath` 的场景同时生效，不单独修改随机行走或座位逻辑。
- 不修改速度、动作选择概率、座位位置或窗口尺寸。

## 测试

在现有宠物移动测试中新增以下断言：

- 斜向目标生成一个直角拐点和最终目标。
- 每一段路径都满足前后两点的 X 相同或 Y 相同。
- 水平目标与垂直目标保持单段移动。
- 当前位置等于目标时返回空路径。
- 目标超出工作区时，限制后的路径仍全部轴对齐。
